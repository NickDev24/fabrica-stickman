# 🏭 Fábrica Autónoma

[![CI](https://github.com/NickDev24/fabrica-stickman/actions/workflows/ci.yml/badge.svg)](https://github.com/NickDev24/fabrica-stickman/actions)
[![npm](https://img.shields.io/npm/v/@nickdev24/fabrica-autonoma)](https://www.npmjs.com/package/@nickdev24/fabrica-autonoma)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Tu fábrica autónoma de contenido (videos stickman + cómics) con una **oficina 2D interactiva** donde agentes stickman te guían paso a paso.

## Quick Start

```bash
npx NickDev24/fabrica-autonoma
```

## Features
- Oficina 2D (Phaser 3) con 4 agentes: Nova, Kai, Luna, Zern
- Conectores: OpenAI, Anthropic, Gemini, ElevenLabs, HeyGen, Runway, MCPs, Skills, Zernio (TikTok/FB/IG/YT)
- CLI publicable, docs VitePress, CI/CD
