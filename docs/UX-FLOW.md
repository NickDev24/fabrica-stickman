# UX Flow

## Onboarding tree
Nova (welcome) -> Kai (APIs) -> Luna (skills) -> Zern (socials) -> complete.

## Error recovery
- Invalid API key: inline error + "¿Cómo obtengo esto?" link + "Explícame como si tuviera 10 años".
- OAuth cancel: retry button, no crash.
- Network failure: offline banner, retry.

## Accessibility
Keyboard navigation, ARIA labels, focus rings, reduced-motion support.
